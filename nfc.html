Program your NFC card

Write your GSA Connect link onto any NFC tag, sticker or card (NTAG213/215/216). Anyone who taps it opens your card.

Event mode & advanced

For GSA tabling: write the same link (e.g. the GSA Connect gallery) to a stack of cards, or switch the link between people.

Locking is permanent. A locked tag can never be rewritten. Your card URL stays the same forever (you edit card.json, not the tag), so locking is safe once the link is final.
iPhone can't write tags from a web page

Apple doesn't allow Web NFC in Safari. iPhones read these tags fine, so writing just takes a free app:

  1. Install NFC Tools (free) from the App Store.
  2. Tap Write → Add a record → URL/URI.
  3. Paste your link (copy it below) and tap OK → Write.
  4. Hold the top edge of your iPhone to the tag.

Or open this page in Chrome on any Android phone to write directly.
